# k-ofl.web.app — 짧은 주소

`https://k-ofl.web.app`을 열면 폰트 창고(`https://maker-ssam.github.io/korean-ofl-fonts/`)로 넘겨준다(302, 임시 넘김). 폰트·페이지는 그대로 GitHub Pages에 있고, Firebase에는 넘겨주기 설정만 있다.

- Firebase 프로젝트 `maker-ssam`의 사이트 `k-ofl`(2026-11-13 만듦)
- 다시 배포: 이 폴더에서 `firebase deploy --only hosting:k-ofl`
- `public/index.html`은 넘겨주기가 안 될 때를 위한 예비 페이지
