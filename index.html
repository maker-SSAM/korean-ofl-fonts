  • 한글 OFL 폰트 …종(2종 예외)을 모두 모았습니다. 선택하여 필요한 폰트를 바로 다운로드 하세요.

갈래로 좁히기

세부 조건으로 좁히기 (쓰임·굵기·모서리 …)
받은 폰트 설치하는 방법

윈도우

  1. 받은 zip을 오른쪽 클릭 → 모두 압축 풀기
  2. 폴더 안의 폰트 파일(.ttf/.otf)을 모두 선택 → 오른쪽 클릭 → 설치 (모든 사용자용은 "모든 사용자용으로 설치")
  3. 한글·PPT·워드를 껐다가 다시 켜면 폰트 목록에 나타납니다.

맥

  1. zip을 더블클릭해 압축을 풉니다.
  2. 폰트 파일(.ttf/.otf)을 더블클릭 → 서체 설치 버튼.
  3. 프로그램을 다시 켜면 목록에 나타납니다.

웹페이지·슬라이드(HTML)에 쓸 때

  1. 카드의 CSS 주소 복사를 누르고, 페이지의 <link rel="stylesheet" href="…">에 붙여 넣습니다.
  2. CSS 안의 font-family 이름으로 글꼴을 지정합니다.

꼭 알아둘 것

  1. 폰트 파일을 그대로 파는 것은 안 됩니다. 수업자료·문서·인쇄물·영상에 쓰는 것은 괜찮습니다.
  2. 나눔 계열 등은 출처 표기를 권장하며, 예외 표시 폰트는 카드의 라이선스를 꼭 읽어 주세요.

0종 선택 · 약 zip 하나로 묶어 저장합니다(폰트마다 폴더, 100종쯤이면 2~3분 걸려요). 풀고 폰트 파일(ttf/otf)을 더블클릭 → 설치.
