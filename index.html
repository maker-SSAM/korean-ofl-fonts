한글 OFL 폰트 창고

누구나 자유롭게 쓰고 다시 나눌 수 있는 한글 폰트 …종. 폰트마다 재배포 근거를 확인했습니다(예외 표시가 붙은 2종은 재배포 문구가 없어 운영자 판단으로 넣은 것 — 라이선스를 꼭 보세요). 웹폰트 CSS · 설치용 zip · 라이선스를 바로 쓸 수 있고, 목록은 fonts.json에 있습니다. 사용법은 저장소 안내.

세부 조건으로 좁히기 (쓰임·굵기·모서리 …)

0종 선택 · 약 내려받기를 누르면 파일이 차례로 저장됩니다. 브라우저가 "여러 파일 다운로드 허용?"을 물으면 허용해 주세요. 받은 zip을 풀고 폰트 파일(ttf/otf)을 더블클릭 → 설치.
폰트 파일은 각 폰트의 라이선스를 따릅니다(대부분 SIL OFL 1.1, 폰트 자체 판매 금지). 네이버 나눔 계열은 출처 표기를 권장합니다. 분류 정보(fonts.json)는 CC BY 4.0입니다.
